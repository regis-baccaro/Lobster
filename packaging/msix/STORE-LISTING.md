## English (en-us)

**Short description**
Convert and edit files by dragging them while holding Shift. Everything runs locally.

**Description**
Lobster converts and edits files without opening an app. Start dragging files in File Explorer
while holding Shift: a circular menu appears under the cursor. Release on an action and the
result appears next to the original — Lobster never overwrites a file.

Images: PNG, JPG, WebP, AVIF, GIF, BMP, TIFF, ICO and PDF (also reads HEIC, SVG, PSD and camera
RAW). Compress, resize, crop (free, 1:1, 16:9…), rotate, mirror, black and white, strip EXIF,
merge into a PDF or an animated GIF.

Video: MP4 (H.264/H.265), WebM, MKV, MOV, AVI, GIF. Compress to a quality or a target size,
change resolution, crop, trim with a preview, rotate, extract audio, mute, change speed, grab a
frame, join clips.

Audio: MP3, M4A, WAV, FLAC, OGG, Opus, AIFF. Compress, trim, normalize, mono, fade, merge.

PDF: export pages as images, extract text, compress, split, extract or delete pages, rotate,
merge.

Documents: Word, Excel, PowerPoint, OpenDocument, RTF, HTML and Markdown to PDF and back.

Everything is processed on your computer: nothing is uploaded, no account, no tracking.
English and French interface, eight color palettes for the radial menu.

## Submission notes for certification

> Lobster is a full-trust desktop app (runFullTrust) because it installs a low-level mouse hook to
> detect Shift + drag in File Explorer and runs local conversion engines. It makes no network
> connections except when the user asks to install ffmpeg through winget. To test: hold Shift and
> start dragging any image in File Explorer, then release on an action in the circular menu; or
> right-click an image › Open with › Lobster.
